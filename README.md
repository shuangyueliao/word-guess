# Word Guess · Five-Letter Word Puzzle

Free single-file HTML5 word puzzle. Guess the hidden 5-letter word in six
tries: green = right spot, yellow = wrong spot, gray = not in the word.
Daily and endless modes, hard mode, streaks and guess-distribution stats.
One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/word-guess/

- Touch and physical keyboard input, procedural WebAudio sounds
- 659 answer words, 1254 extra valid guesses, 1913 words total, no dependencies
- Flip-tile reveal animation, on-screen QWERTY keyboard, hard mode
